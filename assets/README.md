# Game Assets

## Audio
- **music/**: Background music untuk game
  - Main theme dan level themes
  
- **sfx/**: Sound effects
  - collect.mp3: Sound ketika buah dikumpulkan
  - explode.mp3: Sound ketika game over
  - level_up.mp3: Sound ketika naik level (akan ditambahkan)

## Images
- Fruit sprites (apple, banana, orange, etc)
- Basket sprite
- Background elements
- UI elements (buttons, score display)

## Fonts
- Custom fonts untuk UI text

## Shaders
- Particle effects untuk fruit collection
- Visual effects untuk game over
